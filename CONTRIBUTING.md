# Contributing

This repository is a controlled systems-performance research project. Contributions should preserve causal timing semantics, exact-once accounting, explicit measurement boundaries, deterministic configuration, provenance and the distinction between sourced, measured, modelled and derived inputs.

Performance claims require correctness-equivalent work, declared timing boundaries and executed evidence at the cited revision. CUDA/Nsight/NCCL/ASTRA-sim claims must remain conditional until those paths are actually executed.

Do not commit proprietary employer material, private traces, secrets or restricted data.
